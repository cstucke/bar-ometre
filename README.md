# Bar-omètre

## Highlights

- Interactive map
- Unique bar data
- Local and filtered search

## Overview

Bar-omètre is an intuitive local bar tracking web application designed to provide unique insight on events, pricing, and reviews. Created by students for students, this project was made to fill a gap in the current market by giving students and youth unique information.
