CREATE DATABASE paris_bars;

CREATE TABLE bars (
  id BIGINT PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  addr_street VARCHAR(255),
  addr_housenumber VARCHAR(50),
  addr_postcode VARCHAR(10),
  addr_city VARCHAR(100),
  phone VARCHAR(20),
  website VARCHAR(255),
  opening_hours TEXT
);



Then Copy through psql terminal:

psql -U your_username -d paris_bars -c "\COPY bars FROM '/path/to/bars.csv' WITH (FORMAT csv, HEADER true, DELIMITER ',');"

or Import in pgAdmin4 data from .csv file to bars table.



Queries to test if data copied successfully:

SELECT COUNT(*) FROM bars;
SELECT * FROM bars LIMIT 5;
